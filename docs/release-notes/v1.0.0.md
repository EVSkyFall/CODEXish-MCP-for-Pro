The first release of CODEXish. It lets ChatGPT, including GPT Pro, work on your Windows PC through one self-contained MCP server.

## Highlights

- **24 tools for ChatGPT.**
  - Files, with hash-checked writes and patches.
  - Commands in pwsh, Windows PowerShell or cmd, with supervised background processes.
  - Read-only Git.
  - Artifacts for long output.
  - Desktop control through screenshots, UI Automation and input.
- **Connects as a ChatGPT MCP app.** Use **Add → Create MCP App** with OAuth. ChatGPT registers itself through Dynamic Client Registration, and you sign in with a CODEXish password.
- **Built to run unattended.**
  - The tray starts at Windows sign-in, and the server and tunnel restart with backoff.
  - The configuration and ledger recover from damage.
  - CODEXish's own old state is cleaned up after 30 or 90 days.
  - Nothing optional stops the server.
- **Native Windows 11 look.**
  - Lucide icons, and a tray icon whose status dot shows the state.
  - Light and dark mode, and per-monitor DPI.
- **Safety controls.**
  - Folder grants for Read, Write and Shell.
  - Pause, revoke all tokens, and remove registered clients.
  - Every sign-in page names the site it returns to.

## Install

Download `CODEXish-v1.0.0-win-x64.zip`, then follow the [README](https://github.com/EVSkyFall/CODEXish-MCP-for-Pro#install). It covers extracting the zip, publishing the server with Tailscale Funnel, the first run and connecting ChatGPT.

The program is not code-signed, so Windows SmartScreen may ask once.

## Known limits

- **No sandbox.** Commands run with your full Windows rights.
- **No CIMD.** OAuth client ID metadata documents are not implemented.
- **The rest.** The full list is under [Limits and known gaps](https://github.com/EVSkyFall/CODEXish-MCP-for-Pro/blob/main/docs/reference.md#limits-and-known-gaps).
