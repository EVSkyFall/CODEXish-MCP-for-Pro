CODEXish v1.0.2 makes the tray menu show the state of everything and confirm every action.

## Changes

- **Switches you can read.** **Start with Windows** and **Pause changes** are switches. On is filled with the accent color, its knob on the right, and says **On**; off is a muted outline, its knob on the left, and says **Off**. Before, on and off looked the same.
- **Pause changes is one switch.** It replaces the separate Pause changes and Resume changes items.
- **Items grey out when they do not apply.** Examples are **Start server** while the server runs or retries, **Stop server** while it is stopped, and **Start configured tunnel** without a `tunnel.command` or while the server is not listening. **Pause changes** and the session, token and client items need the running server. The menu is read again every time it opens and updates while it stays open.
- **Every action confirms what happened.** A notification says what the action actually did, for example "Server started on port 38451.", "Stopped 2 processes ChatGPT started." or "Start with Windows is on: CODEXish starts when you sign in." A start that is still retrying says so with its cause, and a failure still opens the error window. Windows may hold notifications back, for example under Do Not Disturb; the menu always shows the current state.
- **The first line names every state that is not the default**, for example "Server running · changes paused" or "Server stopped · tunnel stopped". The icon's tooltip shows the same text.
- **A second server on the same `state_dir`** prints one line, `CODEXish: another CODEXish is already running with state_dir <path>; stop it first or use another --state-dir.`, and exits with code 2 instead of a stack trace.
- **A clearer autostart log line.** When the tray rewrites the Startup shortcut, the connection log says what it now starts and why: its target was gone, it had other arguments, or it could not be read. The line is now written even when the configuration loads only after a retry.

## Update

Choose **Exit** in the tray, extract `CODEXish-v1.0.2-win-x64.zip` over `%LOCALAPPDATA%\Programs\Codexish`, then start it again. Your configuration, sign-ins and checkpoints stay in `%LOCALAPPDATA%\Codexish`.
