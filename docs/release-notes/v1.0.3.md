CODEXish v1.0.3 adds a read-only review mode, so a second, local-only CODEXish can give a browser-based model read access to your code and nothing else.

v1.0.2 was never released on its own, so v1.0.3 also includes [v1.0.2's tray changes](v1.0.2.md): switches that show On and Off, greyed items, a notification for every action and a header that names the state.

## Changes

- **`read_only` in `codexish.json`.** With `"read_only": true`, the server offers only 11 tools: `host_capabilities`, `workspace_info`, `fs_list`, `fs_stat`, `fs_read`, `fs_search`, `git_status`, `git_diff`, `git_log`, `artifact_read` and `artifact_search`.
  - Every tool that writes, patches, runs a shell or process, inspects or cancels operations, saves checkpoints or touches the desktop is removed. Calling one gets the MCP "unknown tool" error.
  - Browser mounts are not started, listed or callable.
  - Every root becomes read-only. A root that asked for `write` or `shell` gets the warning "read_only is on, so root '<id>' is read-only."
  - `host_capabilities` and `workspace_info` report `read_only`.
  - `initialize` returns a short read-only text instead of the full harness instructions.
  - Missing or `null` means `false`, which leaves everything as before.
- **Browser-extension origins.** `allow_origins` also accepts an exact `chrome-extension://<id>`, where the id is Chrome's 32 letters from a to p. It is compared without case. Any other scheme, and an extension origin with a path, port or query, is still skipped with a warning, which now reads "is not an exact http(s) or chrome-extension origin and is ignored."

See [Read-only review instance](../reference.md#read-only-review-instance) for a complete configuration. Never publish such an instance through a tunnel.

## Update

Choose **Exit** in the tray, extract `CODEXish-v1.0.3-win-x64.zip` over `%LOCALAPPDATA%\Programs\Codexish`, then start it again. Your configuration, sign-ins and checkpoints stay in `%LOCALAPPDATA%\Codexish`, and an existing configuration without `read_only` behaves exactly as before.
