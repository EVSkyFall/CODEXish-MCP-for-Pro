CODEXish v1.0.1 makes two ChatGPT conversations on one PC keep out of each other's way, and lets `--init` start without a shared folder.

## Changes

- **Checkpoints per line of work.**
  - `session_checkpoint` takes an optional `task`; without one, a checkpoint belongs to `default`.
  - `host_capabilities` keeps `checkpoint`, the newest of all tasks, and adds `checkpoints`, the newest of every task.
  - Retention keeps the newest checkpoint of every task.
  - Your existing checkpoints are kept and belong to `default`.
- **Unique invocation IDs.** All conversations share one connection, so CODEXish cannot tell them apart. An `invocation_id` that another conversation already used with the same arguments returns that earlier result instead of running.
  - The tool descriptions and the server instructions now ask for a unique id for each new action, a short word plus a random suffix such as `run-tests-7f3a9c2e`.
  - If you pasted the [Project custom instructions](https://github.com/EVSkyFall/CODEXish-MCP-for-Pro/blob/main/docs/reference.md#project-custom-instructions), replace them with the new text.
- **`--init` without `--root`.** It writes a configuration that shares no folder yet and says how to add one.
- **Start at sign-in no longer opens the first-run setup.** After a restart the tray could, for a moment, fail to see `codexish.json` and open the setup window, whose **Create configuration** would have replaced your password and secrets. Started at sign-in, the tray now retries loading the file instead (amber icon, every minute) and starts the server as soon as it loads. The Startup shortcut also passes the configuration's full path, and an older shortcut is updated the next time the tray starts.
- **Readable command-line errors.** A missing or malformed argument prints one line, `CODEXish: <message>`, and exits with code 2 instead of a stack trace.

The README has a new note on [running two conversations at once](https://github.com/EVSkyFall/CODEXish-MCP-for-Pro#using-it).

## Update

Choose **Exit** in the tray, extract `CODEXish-v1.0.1-win-x64.zip` over `%LOCALAPPDATA%\Programs\Codexish`, then start it again. Your configuration, sign-ins and checkpoints stay in `%LOCALAPPDATA%\Codexish`.
